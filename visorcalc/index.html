Coating colour for GEP visors. Single films use the same Belcour–Barla evaluation as gepEvalIridescence; past full strength, normal-map A blends into a dichroic quarter-wave stack (a prototype mode, not yet in the shader). Set the coating the way you would in the textures, then read off the values.

Stack constants (global)

Index contrast sets the band width (wider = paler, brighter); pairs set its depth and sharpness. The stack sits on polycarbonate (n 1.586) and replaces the base colour, so it works on top of any livery's visor.

Texture values

      
B is film thickness 0–400 nm in film mode and the stack's band centre 380–780 nm in stack mode; between A 127 and 0 the two blend (a perceptual interpolation). Normal map: four-channel BC7 with ordinary mips. Dielectric substrate F0 is 0.03, as on the cockpit path.
